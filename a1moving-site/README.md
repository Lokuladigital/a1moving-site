# A1Moving — website

Static one-page site for A1Moving (Edmonton & area). No build step: `index.html` plus `assets/`.

## Deploy on Vercel
Import this repo at vercel.com/new. Framework preset: **Other**. Leave build and output settings empty.

## Updating
Edit the source project, run `_build/package.sh`, then commit and push. Vercel redeploys on every push.
